## 1. القرار الاستراتيجي

اعتماد برنامج هندسي واحد يتكون من خمسة مسارات مترابطة:

1. **Lumen** — المنصة التعليمية.
2. **AI Chat App** — تطبيق المحادثة الذكي ومنصة الوكلاء ومساحة العمل.
3. **ERP** — نظام تخطيط موارد المؤسسات متعدد الشركات.
4. **AI Core** — نواة ذكاء اصطناعي مفتوحة الأوزان وخدمات ووكلاء متخصصون.
5. **Unified Ecosystem** — طبقة حوكمة وتكامل مشتركة.

تظل **المرحلة السادسة: الابتكار والتوسع** (المختبرات والمحاكيات والبحث والتطوير وأدوات بناء المشاريع والتقنيات الجديدة) مؤجلة حتى تستقر المسارات الخمسة.

هذا برنامج موحد لتنسيق التوافق، وليس مشروعاً واحداً يدمج المستودعات أو قواعد البيانات أو دورات الإصدارات.

## 2. مبادئ معمارية ملزمة

- لكل منتج مستودعه وفروعه وإصداراته وCI/CD الخاص به.
- قواعد بيانات Lumen وAI Chat App وERP مستقلة؛ لا مشاركة مباشرة للجداول أو قواعد البيانات بين المنتجات.
- التكامل عبر واجهات API وعقود موثقة ومصدّرة بإصدارات واضحة، وليس عبر استيراد كود داخلي أو الوصول المباشر إلى قاعدة منتج آخر.
- لا يعتمد تشغيل المنتج الأساسي على توفر AI Core أو طبقة التكامل. يجب أن يكون تعطل خدمة مشتركة محدود الأثر وقابلاً للاحتواء.
- تُعزل بيانات الشركات داخل ERP على مستوى التطبيق وقاعدة البيانات والملفات والتقارير والمهام الخلفية.
- لا تُنقل بيانات المستخدمين أو الطلاب أو الشركات بين المنتجات إلا لغرض محدد ومصرح به وبأقل قدر لازم.
- لا نقرر SSO أو هوية مركزية شاملة قبل توثيق المتطلبات ونموذج التهديد وخطة التراجع. لا نغيّر أنظمة تسجيل الدخول القائمة لمجرد توحيد الشكل.
- تُحفظ النسخ الأصلية. التغييرات صغيرة وقابلة للعكس، وتُنفذ على فروع وطلبات دمج مناسبة.
- الأولوية للحلول المجانية أو منخفضة التكلفة. لا التزام مالي أو GPU مدفوع دون موافقة صريحة.
- لا أسرار أو مفاتيح أو بيانات إنتاج حساسة في Git أو ملفات الاختبار أو التقارير.
- لا تُعد الوثيقة التاريخية أو وصف PR دليلاً على الحالة الحية؛ يُفحص الفرع والـCommit والـCI والبيئة قبل أي قرار تنفيذي.

### ترتيب سلطة المعلومات

1. **حالة الكود:** رأس الفرع وCommit الفعليان في Git.
2. **حالة PR:** بيانات PR الحية، وHead SHA، وBase SHA، ونتائج CI على الرأس نفسه.
3. **حالة التشغيل:** نتائج فحص بيئة التشغيل الفعلية المؤرخة، لا التوقعات أو ملفات الإعداد وحدها.
4. **قرارات المنتج:** أحدث قرار معتمد داخل مستودع المنتج، بعد التحقق من عدم استبداله.
5. **الأرشيف المركزي:** نسخة حفظ وفهرسة ومصالحة؛ لا يغيّر مصدر المنتج الأصلي ولا يحل محله.

## 5. المسارات الخمسة

### 5.1 Lumen

إكمال واستقرار تجربة الطالب والمدرس والإدارة: الحسابات والصلاحيات، المقررات والدروس والمحتوى، الواجبات والاختبارات والتقييمات، تقدم الطلاب والتقارير، الهاتف، الأداء، الأمن، النسخ الاحتياطي والمراقبة.

LTI 1.3 وAGS تكامل إضافي منفصل. لا يُسمح بأن يوقف تطوير المنصة الأساسية.

### 5.2 AI Chat App

تثبيت الاعتمادية وتجربة المحادثة والملفات والرسائل والأدوات، مع مراجعة PRs الواسعة وتفكيكها إلى تغييرات قابلة للفحص. لا تبدأ ميزات جديدة واسعة قبل حسم بوابات الاستقرار والتشغيل والتوثيق.

### 5.3 ERP

الحفاظ على النسخة الأصلية ثم مواصلة بناء تعدد الشركات على مراحل. دعم القطاعات المختلفة يكون عبر Industry Packs اختيارية، وليس عبر تضخيم نواة واحدة أو تفعيل جميع القطاعات دفعة واحدة.

### 5.4 AI Core

نواة مستقلة قابلة لإعادة الاستخدام، تدعم نماذج مفتوحة الأوزان ووكلاء متخصصين في:
- البرمجة وهندسة البرمجيات.
- Linux وإدارة الأنظمة.
- الشبكات.
- Cloud وDevOps.
- الأمن السيبراني.
- تحليل الملفات والمعرفة والتعلم.

المكونات المرشحة للدراسة: Model Gateway، إدارة مزودين ونماذج، واجهات Agent/Tool، تقييمات، سجلات ومراقبة، وسياسة وصول. لا تُنشأ خدمة تكرر قدرات AI Chat App الموجودة؛ يُحدد ما يُعاد استخدامه وما يُستخرج وما يبقى منتجياً بعد جرد القدرات.

### 5.5 Unified Ecosystem

تحديد عقود التكامل وإصداراتها، وحدود الهوية والتفويض، وسجلات التدقيق، وسياسات البيانات، ومراقبة الاعتمادية، وإجراءات التعافي. لا قاعدة بيانات عالمية مشتركة ولا اعتماد إلزامي على خدمة واحدة.

### 5.6 الابتكار والتوسع — المرحلة السادسة المؤجلة

تظل هذه القدرات ضمن الرؤية طويلة الأجل، وليست ميزات منفذة أو أولوية حالية قبل استقرار المسارات الخمسة:

1. **Research & Discovery:** بحث منظم وجمع أدلة ومقارنة الخيارات والتحقق من المصادر.
2. **Innovation Studio:** تحويل الأفكار إلى مفاهيم وتجارب وتصاميم ونماذج أولية قابلة للتقييم.
3. **Project Forge:** إدارة دورة المشروع من الفكرة والمتطلبات إلى التصميم والتنفيذ والاختبار والتسليم.
4. **Virtual Labs:** مختبرات برمجية وسحابية وشبكية وأمنية وبيانات وإلكترونيات وروبوتات وصناعة.
5. **Smart Technology Operations:** متابعة وتشغيل الأنظمة والأجهزة الذكية والمباني والزراعة والطاقة والمصانع.
6. **Open Innovation Ecosystem:** مشاركة الإضافات والمشاريع والتعاون ضمن مراجعة وصلاحيات وأمن واضح.

لا يبدأ أي من هذه المسارات قبل قرار بدء مستقل وموارد واختبارات قبول محددة.

### 5.7 المختبرات والأجهزة الفعلية

التدرج طويل الأجل هو: محاكاة وبرمجيات مفتوحة أولاً؛ ثم مختبرات البرمجة وLinux والخوادم والشبكات والسحابة وCyber Range؛ ثم AI/Data والإلكترونيات وIoT والروبوتات؛ ثم الصناعة والتوائم الرقمية والربط بالأجهزة الفعلية عند توفر المعدات والتمويل والبيئة الآمنة.

تكاملات محتملة عند الحاجة تشمل MQTT وMatter وOPC UA وROS 2 وEdge Computing والتوائم الرقمية. يجب أن يمر التحكم الفعلي عبر بوابة أوامر وصلاحيات وموافقة بشرية بحسب مستوى الخطر، مع عزل الشبكات وسجلات وإيقاف طارئ وحماية محلية مستقلة. لا يُعتمد على نموذج لغوي بوصفه آلية السلامة الوحيدة للأشخاص أو المعدات.
